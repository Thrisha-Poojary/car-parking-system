# 🚗 Skyline Parking Garage Management System

A Java-based console application that simulates an automated parking garage system. It handles vehicle parking spot allocations across multiple levels, tracks occupancy, and calculates fees with dynamic billing rules.

---

## 🛠️ Key Features

* **Parking Spot Allocation:** Allocates spots on assigned levels (A, B, C) or finds the nearest available spot.
* **Dynamic Fee Calculation:** Computes entry fees, hourly rates, floor surcharges, and enforces a daily maximum price cap.
* **Occupancy Tracking:** Monitors free and occupied slots across all levels.
* **Ticket Generation:** Generates formatted billing tickets for parked vehicles.
